Security Plane
--------------

Security Plane: OS, CA, VPN, LDAP, IAS, ABAC

┌─────────────────────────────────────────────────────────────────────────────┐
│ Security Admin BEAM                             (trusted security services) │
│                                                                             │
│ * Highest privilege, smallest surface                                       │
│ * Owns all long-term keys, HSM/TPM interaction, signing, certificate CA     │
│ * Communicates only with System BEAM over a single, capability-limited,     │
│ * length-prefixed Unix-domain socket (or sealed distribution channel)       │
├─────────────────────────────────────────────────────────────────────────────┤
│ cd      - erpuno/cd      - storage mounts, names, cluster                   │
│ os      - synrc/os       - core system services                             │
│ ca      - synrc/ca       - certificate authority                            │
│ ias     - zencrypted/ias - identity and authentication services             │
│ tss     - synrc/tss      - TSS2 TPM 2.0 Linux HSM                           │
│ kvs     - synrc/kvs      - privileged CAS KV storage (aggregate)            │
│ vpn     - zencrypted/vpn - tunnelling                                       │
│ ldap    - synrc/ldap     - certificates, policy, auth, directory (aggreg.)  │
│ abac    - erpuno/abac    - attribute based access control (aggregate)       │
└─────────────────────────────────────────────────────────────────────────────┘

Control Plane
-------------

Control Planes: Storage, Services (SoA, buses), Protocols

┌─────────────────────────────────────────────────────────────────────────────┐
│ Admin BEAM                                    (privileged network services) │
│                                                                             │
│ * Capability broker, device open, mount, network config, policy             │
│ * Never opens a graphical display or loads non IETF code                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ mqtt    - erpuno/mqtt    - brockering                                       │
│ turn    - erpuno/turn    - streaming (STUN/TURN)                            │
│ rest    - synrc/rest     - HTTP API                                         │
│ asn1    - synrc/asn1     - ASN.1 API                                        │
│ rpc     - synrc/rpc      - BERT API                                         │
│ x422    - zencrypted/protocol - X.422 API                                   │
│ kvs     - synrc/kvs      - key-value storage based on iterators (aggregate) │
└─────────────────────────────────────────────────────────────────────────────┘
